# STORY-24 빌드 현황 조회 기능 확장

## 유형

- Story

## 구현 상태

- 부분 구현

## 우선순위

- 높음

## 요약

운영자가 프로젝트별, 플랜별 빌드 현황을 조회하고 현재 실행 상태와 최근 실패/성공 흐름을 빠르게 파악할 수 있어야 한다.

## 배경

- 현재는 프로젝트/실행 이력의 일부 조회 기반만 있다.
- 운영 콘솔로 사용하려면 현시점의 상태를 빠르게 보여주는 관측 기능이 필요하다.

## 설명

빌드 현황 조회 기능은 프로젝트 단위 운영 가시성을 제공한다. 시스템은 최근 실행 목록, 현재 실행 중인 항목, 최근 실패 빌드, 마지막 성공 빌드, 상태별 집계를 제공할 수 있어야 한다. 조회 결과는 프로젝트 화면, 대시보드, API 소비자에서 재사용될 수 있어야 하며, 동일한 상태 계산 기준을 사용해야 한다.

## 범위

### 포함

- 프로젝트별/플랜별 빌드 상태 조회
- 상태별 집계
- 최근 성공/실패/실행 중 항목 조회
- 조회 API

### 제외

- 실시간 푸시 알림
- 로그 본문 전문 뷰어

## 수용 기준

- 빌드 상태를 프로젝트별, 플랜별, 상태별로 조회할 수 있다.
- 최근 실패와 마지막 성공 항목을 구분해 제공할 수 있다.
- 조회 기능이 UI와 API에서 공통 상태 모델을 사용한다.
- 운영자가 현재 실행 중인 빌드를 식별할 수 있다.
