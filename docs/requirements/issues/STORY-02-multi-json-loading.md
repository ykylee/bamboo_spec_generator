# STORY-02 다중 JSON 입력 로딩 및 빌드 정의 식별 기능 구현

## 유형

- Story

## 요약

앱이 여러 JSON 파일을 읽고 각 파일의 빌드 정의를 식별해 내부 모델로 변환할 수 있도록 한다.

## 배경

이 프로젝트는 단일 빌드가 아니라 여러 타겟 빌드를 처리해야 한다. 따라서 파일 탐색, 로드, 검증, 내부 모델 변환이 안정적으로 동작해야 전체 생성 파이프라인이 성립한다.

## 설명

앱은 지정된 파일 또는 디렉터리에서 JSON 입력을 읽고, 각 빌드 정의를 구분해 내부 표현으로 변환해야 한다. 연도별 관리 구조를 해석할 수 있어야 하며, 잘못된 입력에 대해서는 식별 가능한 오류를 제공해야 한다.

## 수용 기준

- 여러 JSON 파일을 입력으로 받을 수 있다.
- 각 JSON 파일을 개별 빌드 정의로 식별할 수 있다.
- 연도별 관리 구조를 해석할 수 있다.
- 유효하지 않은 JSON 또는 필수 필드 누락 시 오류를 반환한다.
- 후속 코드 생성 단계에 전달 가능한 내부 모델이 생성된다.
