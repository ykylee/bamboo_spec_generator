# STORY-04 빌드별 산출물 분리 및 등록 단위 구조 설계

## 유형

- Story

## 요약

여러 타겟 빌드의 생성 결과를 Bamboo에 개별 등록 가능한 단위로 분리하는 산출물 구조를 설계한다.

## 배경

여러 빌드를 한 번에 처리하더라도 실제 운영에서는 빌드별로 생성 결과를 식별하고 관리할 수 있어야 한다. 산출물 경로와 파일 구조가 불명확하면 생성물 관리와 등록 절차가 어려워진다.

## 설명

생성된 Bamboo Specs Java 코드가 빌드별로 구분되도록 출력 구조를 정의한다. 필요하면 연도, 빌드 식별자, 출력 디렉터리 규칙을 포함하고, 개별 등록에 적합한 단위를 보장해야 한다.

## 수용 기준

- 빌드별 산출물 분리 원칙이 정의되어 있다.
- 연도와 빌드 식별자를 반영한 출력 규칙이 정의되어 있다.
- 여러 빌드를 한 번에 생성하더라도 결과를 개별적으로 식별할 수 있다.
- Bamboo 개별 등록 단위로 활용 가능한 구조가 문서화되어 있다.

## 의존성

- STORY-01 JSON 스키마 및 연도별 관리 구조 정의
- STORY-02 다중 JSON 입력 로딩 및 빌드 정의 식별 기능 구현
- STORY-03 Bamboo Specs Java 코드 생성 기능 구현
