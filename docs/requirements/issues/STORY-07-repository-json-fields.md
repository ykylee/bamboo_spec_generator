# STORY-07 저장소 연결용 JSON 필드 및 검증 규칙 정의

## 유형

- Story

## 요약

Bitbucket 저장소 연결에 필요한 `projectKey`, `repoSlug` 및 관련 검증 규칙을 입력 JSON 모델에 정의한다.

## 배경

저장소 연결 정보가 입력 모델에서 불명확하면 생성 로직이 환경 의존적으로 변하고, 브랜치 연결 및 트리거 생성도 일관되게 처리하기 어렵다.

## 설명

시스템은 입력 JSON에서 Bitbucket 저장소를 식별할 수 있도록 최소 필드를 정의해야 한다. 필수 필드는 `projectKey`, `repoSlug`이며, 필요 시 사전 등록 여부나 연결 모드를 표현할 보조 필드를 추가할 수 있다. 검증 로직은 필수값 누락과 형식 오류를 조기에 식별할 수 있어야 한다.

## 수용 기준

- 입력 JSON 모델에 `projectKey`, `repoSlug` 필드가 정의된다.
- 두 필드는 저장소 연결 시 필수값으로 검증된다.
- 필요 시 사전 등록 여부 또는 연결 모드를 표현할 확장 필드가 정의된다.
- 검증 실패 시 어떤 필드가 누락되었는지 식별 가능한 오류가 제공된다.
