## 요약

운영 데이터를 외부 시스템과 내부 사용자가 활용할 수 있도록 Django Ninja 기반 API와 조회용 웹 프론트엔드를 도입한다.

## 배경

- 프로젝트, 저장소, 빌드 플랜, 버전, 실행 이력은 시스템 간 연동과 운영 조회에 함께 사용된다.
- 준비 스테이지 변수 조회와 실행 결과 적재도 API 경계로 노출하면 연동이 단순해진다.
- 초기 UI는 편집보다 조회가 더 중요하다.

## 설명

운영 백엔드 위에 Django Ninja 기반 API를 제공한다. API는 프로젝트/플랜/버전/실행 이력 조회와 준비 스테이지 변수 컨텍스트 조회, 실행 결과 적재를 지원해야 한다. 생성기는 보안상 이 API를 통해서만 운영 데이터를 조회해야 한다. 웹 프론트엔드는 초기에는 읽기 전용 조회 화면으로 제한하고, Django 템플릿 또는 Django 내부 뷰 기반으로 시작할 수 있다. 현재 코드에는 활성 정의 조회, 준비 컨텍스트 조회, 실행 시작/종료 적재, 프로젝트 조회 API와 프로젝트 목록/상세 기본 화면이 추가되었다.

## 범위

### 포함

- Django Ninja 기반 API
- 프로젝트/플랜/버전/실행 이력 조회 엔드포인트
- 준비 스테이지 변수 컨텍스트 조회 엔드포인트
- 빌드 실행 결과 적재 엔드포인트
- 조회용 웹 프론트엔드

### 제외

- 고급 편집 화면
- 별도 SPA 프론트엔드 강제

## 수용 기준

- Ninja 기반 API 사용 방향이 정의된다.
- 준비 스테이지 조회와 실행 결과 적재 API 범위가 정의된다.
- 조회용 프론트엔드 범위가 정의된다.
- 초기 UI가 조회 중심 범위임이 명시된다.
- 현재 기준 기본 API 경로와 조회용 화면 초안이 코드에 반영되어 있다.
