# STORY-11 빌드 작업 하위 경로 지정 지원

## 유형

- Story

## 구현 상태

- 구현됨
- `subPath` 파싱, 검증, 스크립트 렌더링 반영이 구현되어 있다.

## 우선순위

- 유지

## 요약

입력 JSON에서 빌드 작업 하위 경로를 지정해, 생성된 플랜이 저장소 루트가 아닌 지정 경로를 기준으로 준비, 빌드, 정적 분석을 수행할 수 있어야 한다.

## 배경

실제 프로젝트는 솔루션 파일이나 빌드 스크립트가 저장소 하위 디렉터리에 놓인 경우가 많다. 빌드 기준 경로가 루트로 고정되면 모노레포나 다중 애플리케이션 저장소를 유연하게 지원하기 어렵다.

## 설명

시스템은 입력 JSON에 `subPath` 같은 작업 하위 경로 필드를 정의해야 한다. 해당 값이 있으면 생성된 준비, 빌드, 정적 분석 스크립트는 모두 그 경로를 작업 디렉터리로 사용해야 하며, `Directory.Build.targets` 같은 보조 파일도 동일 경로에 생성해야 한다. 값이 없으면 기존과 동일하게 저장소 루트를 기본 작업 위치로 사용해야 한다. 경로는 저장소 내부 상대경로만 허용해야 한다.

## 수용 기준

- 입력 JSON 모델에 작업 하위 경로 필드가 정의되어 있다.
- 필드 생략 시 저장소 루트를 기본 작업 위치로 사용한다고 정의되어 있다.
- 준비, 빌드, 정적 분석 스크립트가 동일한 작업 하위 경로를 기준으로 실행된다고 정의되어 있다.
- `Directory.Build.targets` 같은 보조 파일이 작업 하위 경로에 생성된다고 정의되어 있다.
- 저장소 외부 경로를 막기 위한 상대경로 검증 규칙이 정의되어 있다.
