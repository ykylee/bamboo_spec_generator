# STORY-22 프로젝트 정보 조회 및 수정 기능 확장

## 유형

- Story

## 구현 상태

- 부분 구현

## 우선순위

- 중간

## 요약

운영자가 프로젝트 정보를 조회하고 필요한 운영 메타데이터를 수정할 수 있어야 한다.

## 배경

- 현재는 프로젝트 목록/상세 조회 초안만 있으며 수정 기능은 없다.
- 운영 중에는 프로젝트 이름, 설명, 대표 저장소, 상태 같은 정보가 변경될 수 있다.

## 설명

프로젝트 조회/수정 기능은 등록된 프로젝트를 운영 기준에 맞게 유지하기 위한 핵심 기능이다. 조회 화면과 API는 프로젝트 기본 정보, 연결 저장소, 연결 플랜, 최근 실행 요약을 제공해야 한다. 수정 기능은 프로젝트 표시명, 설명, 상태, 대표 저장소, 운영 속성 같은 메타데이터를 변경할 수 있어야 한다. 변경 이력 추적을 위해 수정자와 수정 시각 저장도 고려해야 한다.

## 범위

### 포함

- 프로젝트 상세 조회 정보 확장
- 프로젝트 수정 API
- 수정자 및 수정 시각 기록

### 제외

- 프로젝트 삭제
- 고급 diff/감사 화면

## 수용 기준

- 프로젝트 상세 조회 정보 범위가 정의된다.
- 프로젝트 기본 메타데이터를 수정할 수 있다.
- 수정 시 수정자와 수정 시각을 기록할 수 있다.
- 조회와 수정 기능이 같은 기준 데이터 모델을 사용한다.
