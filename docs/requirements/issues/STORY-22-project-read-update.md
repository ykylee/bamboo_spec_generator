# STORY-22 프로젝트 정보 조회 및 수정 기능 확장

## 유형

- Story

## 구현 상태

- 부분 구현

## 우선순위

- 중간

## 요약

운영자가 프로젝트 정보를 조회하고 필요한 운영 메타데이터를 수정할 수 있어야 하며, 등록 UI는 필요할 때만 펼쳐지는 형태로 제공할 수 있어야 한다.

## 배경

- 현재는 프로젝트 목록/상세 조회 초안만 있으며 수정 기능은 없다.
- 운영 중에는 프로젝트 이름, 설명, 대표 저장소, 상태 같은 정보가 변경될 수 있다.

## 설명

프로젝트 조회/수정 기능은 등록된 프로젝트를 운영 기준에 맞게 유지하기 위한 핵심 기능이다. 조회 화면과 API는 프로젝트 기본 정보, 연결 저장소, 연결 플랜, 최근 실행 요약을 제공해야 한다. 수정 기능은 프로젝트 표시명, 설명, 상태, 대표 저장소, 운영 속성 같은 메타데이터를 변경할 수 있어야 한다. 메인 페이지 등록 UI는 평소에는 접힌 상태로 두고, 사용자가 등록 버튼을 눌렀을 때만 펼칠 수 있어야 한다. 입력 시에는 기존에 등록된 Jira Project Key, Bitbucket Project Key, 저장소 slug, Coverity 정보 같은 메타데이터를 선택 후보로 제안할 수 있어야 한다. 이때 저장소와 빌드 관계를 쉽게 읽을 수 있도록 저장소 블록과 그 하위의 빌드 블록 구조를 유지하는 것이 바람직하다. 변경 이력 추적을 위해 수정자와 수정 시각 저장도 고려해야 한다.

## 범위

### 포함

- 프로젝트 상세 조회 정보 확장
- 프로젝트 수정 API
- 접힘/펼침 방식의 등록 UI
- 기존 등록 데이터 기반 선택 후보 제안
- 저장소-빌드 계층 구조의 조회/편집 일관성
- 수정자 및 수정 시각 기록

### 제외

- 프로젝트 삭제
- 고급 diff/감사 화면

## 수용 기준

- 프로젝트 상세 조회 정보 범위가 정의된다.
- 프로젝트 기본 메타데이터를 수정할 수 있다.
- 등록 UI가 기본 접힘 상태로 제공된다.
- 기존 프로젝트/저장소 메타데이터를 입력 후보로 제안할 수 있다.
- 조회/수정 화면에서 저장소와 하위 빌드 관계를 일관되게 표시할 수 있다.
- 수정 시 수정자와 수정 시각을 기록할 수 있다.
- 조회와 수정 기능이 같은 기준 데이터 모델을 사용한다.
