# STORY-29 다중 CI 도구 모드 전환 및 공통 상단 네비게이션 도입

## 유형

- Story

## 구현 상태

- 신규 요구사항

## 우선순위

- 높음

## 요약

운영 콘솔은 상단 버튼 또는 탭을 통해 `Bamboo 관리`와 `Jenkins 관리` 모드를 전환할 수 있어야 하며, 모드가 바뀌어도 메뉴 구조와 화면 배치는 공통된 운영 경험을 유지해야 한다.

## 배경

- 현재 UI는 Bamboo 중심 흐름을 전제로 구성되어 있다.
- Jenkins를 추가해도 화면 구조가 완전히 달라지면 운영자가 도구별로 다른 제품을 학습해야 하는 문제가 생긴다.

## 설명

이 기능은 운영 콘솔의 최상위 탐색 구조를 정의한다. 사용자는 상단 영역에서 현재 관리 중인 CI 도구를 명확히 인지하고 전환할 수 있어야 한다. 전환 이후에도 프로젝트 목록, 상태 대시보드, 상세 화면, 등록 진입점 같은 핵심 동선은 동일해야 한다. 공통 구조를 유지하되, 모드 전환으로 인해 조회 대상 데이터와 일부 도구별 세부 용어만 바뀌는 형태가 바람직하다.

## 범위

### 포함

- 상단 CI 도구 전환 버튼 또는 탭
- 현재 모드 상태 유지 방식 정의
- 공통 메뉴/대시보드/상세 구조 정렬
- 모드 전환 시 도구별 데이터 소스 연결 기준 정의

### 제외

- 세부 테마 컬러 정의
- Jenkins 등록 폼 상세 설계

## 수용 기준

- 사용자가 상단 UI에서 Bamboo/Jenkins 모드를 전환할 수 있다.
- 현재 모드가 화면 전반에서 일관되게 유지된다.
- 전환 후에도 공통 메뉴 구조와 주요 CTA 위치가 유지된다.
- 모드 전환이 프로젝트 목록, 대시보드, 상세 화면 데이터 범위에 반영된다.
