# EPIC-04 다중 CI 콘솔 및 Jenkins 운영 확장

## 유형

- Epic

## 구현 상태

- 신규 요구사항

## 우선순위

- 높음

## 요약

`bamboo_spec_generator`를 Bamboo 전용 운영 콘솔에서 Bamboo와 Jenkins를 함께 관리하는 공통 CI 콘솔로 확장한다. 상단 UI에서 `Bamboo 관리`와 `Jenkins 관리`를 전환할 수 있어야 하며, 공통 정보 구조와 운영 문구는 유지하되 Bamboo 모드는 밝은 파란색, Jenkins 모드는 밝은 빨간색 테마를 사용한다. 또한 Jenkins도 Bamboo Specs와 유사하게 시스템을 통해 프로젝트와 빌드 잡을 등록할 수 있어야 한다.

## 배경

- 현재 운영 UI와 메타데이터 모델은 Bamboo 중심으로 정리되어 있다.
- 실제 조직에서는 Bamboo와 Jenkins가 병행 사용될 수 있으므로 단일 도구 전용 콘솔은 운영 표준화에 한계가 있다.
- 도구가 달라도 공통 운영 경험을 유지하면 사용자 학습 비용과 운영 절차 편차를 줄일 수 있다.

## 설명

이 Epic은 제품의 관리 대상을 Bamboo 단일 도구에서 복수 CI 도구로 확장하는 요구를 다룬다. 사용자는 상단 전환 버튼으로 Bamboo 관리와 Jenkins 관리를 오갈 수 있어야 한다. 전환 이후에도 대시보드, 목록, 상세 화면의 구조와 주요 CTA 위치는 가능한 한 동일해야 하며, 현재 선택된 도구를 즉시 인지할 수 있도록 도구별 대표 색상을 적용해야 한다. Bamboo 모드에서는 밝은 파란색 계열, Jenkins 모드에서는 밝은 빨간색 계열을 사용한다.

등록 기능도 도구 확장을 반영해야 한다. Bamboo 쪽은 기존처럼 Specs 생성과 플랜 등록 흐름을 유지하고, Jenkins 쪽은 프로젝트와 빌드 잡을 등록하는 흐름을 제공해야 한다. 이때 프로젝트/저장소/빌드 같은 공통 개념은 최대한 재사용하되, 도구별 전용 필드는 별도로 수용할 수 있는 공통 도메인/API 구조가 필요하다.

## 범위

### 포함

- 상단 CI 도구 모드 전환 UI
- Bamboo/Jenkins 공통 정보 구조 정의
- 도구별 테마 컬러와 디자인 토큰 정의
- Jenkins 프로젝트 등록
- Jenkins 빌드 잡 등록
- CI 도구 유형을 포함한 공통 도메인/API 모델 확장
- Jenkins 시스템 운영 현황 조회

### 제외

- Jenkins 서버에 대한 실제 job 생성 자동화
- Bamboo/Jenkins 외 추가 CI 도구 지원
- 도구별 브랜드 가이드 전체 반영

## 수용 기준

- 상단에서 `Bamboo 관리`와 `Jenkins 관리` 모드를 전환하는 요구가 정의된다.
- 두 모드가 공통 UI 구조와 운영 문구를 유지해야 한다는 요구가 정의된다.
- Bamboo는 밝은 파란색, Jenkins는 밝은 빨간색 테마를 사용한다는 요구가 정의된다.
- Jenkins 프로젝트와 빌드 잡 등록 요구가 정의된다.
- CI 도구 유형을 포함한 공통 API/도메인 모델 확장 요구가 정의된다.
- Jenkins 시스템 운영 현황 조회 요구가 정의된다.
