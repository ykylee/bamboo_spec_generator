# STORY-25 Bamboo 시스템 운영 현황 조회 기능 도입

## 유형

- Story

## 구현 상태

- 미구현

## 우선순위

- 중간

## 요약

운영자가 Bamboo 시스템 자체의 운영 상태를 확인할 수 있도록 에이전트 현황과 수행 중인 작업을 조회할 수 있어야 한다.

## 배경

- 프로젝트 빌드 현황만으로는 인프라 병목이나 Bamboo 자체 이슈를 파악하기 어렵다.
- 에이전트 가용성, 작업 점유 현황, 대기열 상태는 운영 판단에 직접 필요하다.

## 설명

시스템은 Bamboo API 또는 동등한 연동 수단을 통해 에이전트 상태와 현재 수행 중인 작업 정보를 조회할 수 있어야 한다. 가능하면 에이전트별 이름, 온라인 여부, 현재 작업, 마지막 heartbeat, 태그 또는 capability 요약을 함께 제공한다. 수행 중인 작업은 프로젝트/플랜 관점 조회와 구분된 Bamboo 시스템 관점 화면 또는 API로 제공한다.

이 Story는 Bamboo 전용 운영 현황을 다룬다. 다중 CI 콘솔 확장 이후에도 Bamboo 에이전트/capability 특화 정보는 별도 Story로 유지하고, Jenkins 노드/큐 관점 운영 현황은 별도 Story에서 정의한다. 공통 화면 구조와 API 규칙은 상위 운영 API 표준과 다중 CI 콘솔 설계를 따른다.

## 범위

### 포함

- 에이전트 상태 조회
- 수행 중 작업 조회
- 대기 중 작업 조회
- 운영 현황 API

### 제외

- 에이전트 제어 기능
- Bamboo 서버 설정 편집 기능

## 수용 기준

- Bamboo 에이전트 상태를 조회할 수 있다.
- 현재 수행 중인 작업과 대기 중인 작업을 조회할 수 있다.
- 프로젝트 현황과 시스템 현황을 구분해 제공할 수 있다.
- 관련 기능이 API로 제공된다.
