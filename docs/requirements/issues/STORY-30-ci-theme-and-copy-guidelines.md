# STORY-30 CI 도구별 테마 컬러와 공통 UI 문구 정비

## 유형

- Story

## 구현 상태

- 신규 요구사항

## 우선순위

- 중간

## 요약

운영 콘솔은 Bamboo 모드에서 밝은 파란색, Jenkins 모드에서 밝은 빨간색을 대표 테마 컬러로 사용해야 하며, 전체 UI 문구와 정보 구조는 일반적인 CI 운영 관점으로 유지해야 한다.

## 배경

- 도구 전환이 가능해지면 사용자는 현재 어떤 도구를 보고 있는지 시각적으로 즉시 이해할 수 있어야 한다.
- 특정 도구명에 과도하게 묶인 문구가 남아 있으면 공통 콘솔 구조가 깨지고 유지보수 비용이 커진다.

## 설명

이 Story는 공통 콘솔의 시각적 식별 기준과 카피 가이드를 정의한다. 모드별 색상은 현재 선택된 도구를 인지시키는 최소한의 신호로 사용하고, 화면 구성 자체는 브랜드별로 완전히 갈라지지 않게 유지한다. 제목, 빈 상태, 카드 라벨, 필터 명칭, 상세 요약 문구는 가능하면 `프로젝트`, `빌드`, `잡`, `상태`, `큐`, `노드`처럼 일반적인 CI 용어를 우선 사용해야 한다.

## 범위

### 포함

- Bamboo/Jenkins 모드별 대표 테마 컬러 정의
- 공통 디자인 토큰 적용 범위 정의
- 공통 UI 문구 가이드
- 도구명 직접 노출이 필요한 영역 식별

### 제외

- 전체 브랜딩 리뉴얼
- 도구별 아이콘 세트 재설계

## 수용 기준

- Bamboo 모드의 대표 색상이 밝은 파란색으로 정의된다.
- Jenkins 모드의 대표 색상이 밝은 빨간색으로 정의된다.
- 공통 화면에서 사용할 일반적인 CI 운영 문구 기준이 정의된다.
- 도구별 고유 명칭을 허용하는 예외 영역이 식별된다.

## 오픈 이슈

- 상태 배지와 차트 색상도 모드별로 전부 전환할지 일부 핵심 요소만 전환할지 결정 필요
- `플랜`, `잡`, `파이프라인` 같은 용어를 어떤 공통 추상어로 묶을지 결정 필요
