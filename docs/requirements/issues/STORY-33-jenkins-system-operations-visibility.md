# STORY-33 Jenkins 시스템 운영 현황 조회 기능 도입

## 유형

- Story

## 구현 상태

- 신규 요구사항

## 우선순위

- 높음

## 요약

운영자가 Jenkins 시스템 자체의 운영 상태를 확인할 수 있도록 노드 현황, 실행 중인 잡, 큐 대기 작업을 조회할 수 있어야 한다.

## 배경

- 다중 CI 콘솔에서 Jenkins를 지원하더라도 프로젝트 목록만 제공하면 인프라 병목과 Jenkins 자체 이상을 확인하기 어렵다.
- 노드 가용성, executor 점유, 큐 적체는 운영 판단에 직접 필요하다.

## 설명

시스템은 Jenkins API 또는 동등한 연동 수단을 통해 노드 상태, 현재 실행 중인 잡, 큐 대기 작업 정보를 조회할 수 있어야 한다. 가능하면 노드별 이름, 온라인 여부, executor 사용량, 현재 작업, 마지막 연결 상태, 라벨 요약을 함께 제공한다. 수행 중인 작업과 큐 상태는 프로젝트/잡 관점 조회와 구분된 Jenkins 시스템 관점 화면 또는 API로 제공한다.

## 범위

### 포함

- Jenkins 노드 상태 조회
- 실행 중 잡 조회
- 큐 대기 작업 조회
- Jenkins 운영 현황 API

### 제외

- Jenkins 노드 on/off 제어
- Jenkins 글로벌 설정 편집

## 수용 기준

- Jenkins 노드 상태를 조회할 수 있다.
- 현재 실행 중인 잡과 큐 대기 작업을 조회할 수 있다.
- 프로젝트 현황과 시스템 현황을 구분해 제공할 수 있다.
- 관련 기능이 API로 제공된다.
